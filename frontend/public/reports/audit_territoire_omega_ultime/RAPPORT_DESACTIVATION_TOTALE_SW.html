§1 — STRATÉGIE KILLSWITCH (Articles 3-4)

Suppression simple impossible — un client qui possède déjà un SW v9.x actif continuerait de l'utiliser, et un 404 sur /sw.js ne désinscrit PAS le SW existant. La solution institutionnelle est un SW killswitch qui :

  1. Install : self.skipWaiting() — prend immédiatement le contrôle.
  2. Activate :
    1. Purge totale CacheStorage (caches.delete() sur toutes les keys).
    2. Auto-désinscription (self.registration.unregister()).
    3. Claim + reload de tous les clients (clients.claim() + client.navigate(client.url)).
  3. Aucun fetch handler — toutes les requêtes vont directement au réseau.
