1. Diagnostic racine

Les 9 paramètres nutrition (besoins_proteines, besoins_energetiques, 3 minéraux, 4 saisons) sont stockés sous forme de listes textuelles qualitatives au lieu du format institutionnel {value, signature}. La fonction de normalisation _coerce_float retourne 0.0 sur ces listes.

2. Format institutionnel attendu — {value, signature}

{
  "value": "<float | object {disponibilite, ration_kg, categorie}>",
  "signature": {
    "type": "<float | object | bool>",
    "unit": "<unité SI ou métabolique>",
    "source": "<référence scientifique sourcée>",
    "range": "<intervalle min..max validé>",
    "semantics": "<description institutionnelle>"
  }
}

Règles de normalisation saisonnière

  • Chaque saison fournit {disponibilite: bool, ration_kg: float, categorie: str}.
  • ration_kg = 0 + disponibilite=False = saison critique (hibernation acceptée pour OURS_NOIR.hiver).
  • Score saison = 100 si (disponibilite=True ET ration_kg > 0), sinon 0.
  • Score saisons = moyenne(printemps, ete, automne, hiver) — 4 valeurs.

Règles de normalisation minéraux

  • Sodium ∈ [0..2.0] g/kg MS → norm 0..100 = value/2.0 * 100 (clampé).
  • Calcium ∈ [0..5.0] g/kg MS → norm 0..100 = value/5.0 * 100 (clampé).
  • Magnésium ∈ [0..2.0] g/kg MS → norm 0..100 = value/2.0 * 100 (clampé).
  • Pour DINDON_SAUVAGE le calcium peut atteindre 25 g/kg (œufs) — borne supérieure adaptée 0..40.

Règles protéines / énergie

  • Protéines (cervidés) ∈ [0..30%] MS → norm 0..100 = value/30 * 100.
  • Énergie kcal/jour : norme par espèce — chevreuil [0..5000], orignal [0..50000], ours [0..20000], wapiti [0..40000], dindon [0..500].

4. Valeurs minimales requises pour NUTRITION_MASTER > 90

Pour NUTRITION_MASTER > 90, il faut que le score moyen par espèce ≥ 90. Avec la formule actuelle (moyenne 5 paramètres × 5 espèces), les 5 cibles minimales par espèce sont : protéines/30 ≥ 0.90, énergie ≥ borne sup-10%, minéraux Na/Ca/Mg simultanément à seuils nominaux.

Note institutionnelle : Atteindre 90 simultanément sur les 5 paramètres minéraux demande une saturation rare en milieu naturel. La cible institutionnelle réaliste est NUTRITION_MASTER ∈ [60..80] avec les valeurs nominales sourcées.
