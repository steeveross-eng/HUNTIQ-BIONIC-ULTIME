- [ ] Rupture avec le modèle "hotspot = dérivé d'affût/zone"

> Détection macro → micro → fine
- [ ] Macro : zones de rut régionales (savoirs ethnographiques)
- [ ] Méso : convergences forestières (vallons, cols, lisières)
- [ ] Micro : grattages, frottis, passages répétés

> Hotspots distincts par saison
- [ ] Rut (oct-nov) : points de rencontre mâles/femelles

- [ ] Élevage (mai-juin) : femelles + faons
